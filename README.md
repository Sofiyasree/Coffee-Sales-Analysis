# ☕ Coffee-Sales-Analysis
A complete Excel-based data analytics project where I analyzed sales trends, customer behavior, and category performance using a Coffee Sales dataset.

📌 Project Overview
This project focuses on performing data cleaning, analysis, and dashboard creation in Microsoft Excel. The dataset contains information such as:
SaleID
Year & Month
CoffeeType
Size
Region & Store
Price, Quantity, TotalAmount

🔍 Key Analyses Performed
Total Sales by Region
Sales by Coffee Category
Monthly Sales Trend
Gender-based Sales Comparison
Store-wise Top Performers
Yearly Revenue Growth
Coffee Size-wise Average Sales

📊 Dashboard Features
Dynamic Pivot Charts
Trend Graphs
Category Comparisons
Interactive Visuals for Business Insights

🛠️ Tools & Skills
Microsoft Excel
PivotTables & PivotCharts
Excel Functions (SUMIF, AVERAGE, IF, etc.)
Data Cleaning
Dashboard Design
